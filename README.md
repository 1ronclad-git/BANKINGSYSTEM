# Console-based Banking System

## Overview
This is a small console-based Banking System build with Java. It allows users to create accounts, check balance, deposit, withdraw, transfer money, and view transaction history.
The project demonstrates object-oriented programming, DAO pattern, and database integration using SQL.

## Features
- Account creation with auto-generated account numbers
- Balance inquiry
- Deposit, withdraw, and transfer transactions
- Transaction History
- Console interface

## Technologies Used
- Java (OOP concepts, enums, DAO patterns)
- JDBC for database connectivity
- SQL for data storage and retrieval
